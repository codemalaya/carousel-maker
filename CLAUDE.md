# carousel-maker

Carousel = JSON (`src/core/schema.ts`). Formats in `FORMATS`: 1:1, 4:5, 9:16 (social), 16:9 (1920x1080) and 4:3 (1440x1080) for presentations; renderer, PDF, preview and lint all read size from there. One renderer (`src/core/render.ts`) feeds web editor and Playwright PNG export.

## Projects
`projects/<id>/` = `carousel.json` + `assets/` (images used by slides) + `references/` (style refs, for agents to look at).
Deleting a project moves it to `projects/.trash`. The only hard delete is "Hapus permanen" / "Kosongkan sampah" on the trash page (`Trash.tsx`, `?trash=1`, confirmed); MCP and CLI never hard-delete. The trash page is ONE mixed list (newest first, kind badge) of projects (`projects/.trash`), brand kits (`brands/.trash`), slide templates (`templates/.trash`) and plan slots (`data/planner.trash.json`, entries carry `deleted`): `/api/trash` (projects), `/api/trash/brand[/:name]`, `/api/trash/template[/:name[/spec|assets/:file]]`, `/api/trash/plan[/:id]`; restore never overwrites (taken id -> `<id>-restored[-n]`, plan slot gets a new id if taken). Anything new that "moves to trash" must get list/restore/purge there too. Storage lives in `src/core/projects.ts`; Vite API, MCP and CLI all use it.

## Layout
- `src/core` schema, render, projects (storage), headless (Playwright render + lint)
- `src/server/api.ts` REST API used by the editor (`/api/projects/...`, incl. `export?format=png|zip|pdf|html|mp4|gif&slide=N&scale=1|2[&fps=&hold=&stepGap=]`)
- `src/cli` `npm run carousel -- list | new <id> [--from <id>] | render [id] [--pdf|--html|--mp4|--gif] [--scale 2] [--fps 30] [--hold 1500] [--step-gap 1000] [--out dir] | lint [id]`
- `src/mcp/server.ts` MCP tools; every tool takes optional `project` (default env `CAROUSEL_PROJECT`, else "default")
- `src/web` Vite editor (React + Tailwind v4 + shadcn/ui in `src/web/components/ui`, alias `@/` = `src/web`; add components with `npx shadcn@latest add <name>`)
  Folders in `src/web` (file names below are unique, find them by name; import with `@/<folder>/<File>`, `core` is relative `../../core/...`): `app/` (App routing, AppShell, Header, theme, dialogs) | `pages/{home,planner,brands,trash}/` | `editor/` (`Workspace.tsx` = the editor screen, `useEditor`, `useEditorKeys`, Toolbar) with `canvas/` (Canvas + `useInlineEdit`, `dragElement`, `guideDrag`, `geometry`, `snap`, Rulers, GuidesLayer, ZoomControl), `inspector/` (Inspector + `fields.tsx`, `BrandRow`, `ImageFields`, ExportBar, LayersList), `panel/` (SlidePanel, ProjectMenu, Resizer), `ai/` (AgentBar, agentRuns), `present/` (Present, Preview) | `shared/` (api, SlideView, Sortable, small widgets) | `components/ui` (shadcn). Home is split into `Thumb`, `Hero`, `ProjectItems` (Card/Row/menus), `homeData.ts`; Planner into `PlanChip`, `ItemDialog`, `planUtils.ts`. Entry stays `src/web/main.tsx` + `index.html`; build output goes to `dist/` at the repo root. New code goes in the matching folder, not the root of `src/web`.
  Themes: light/dark via `.dark` class on <html> (`theme.tsx`, tokens in `styles.css`). Native prompt/confirm/alert are replaced by `dialogs.tsx` (`useDialogs().ask/confirm`) and `sonner` toasts.
  Layout: header 56px (logo + app name | context chip: project, Slide n/N, format menu | shortcuts dialog `?`, save status, theme; grid rows in `styles.css`, `Resizer.tsx` top offset must match) | slide panel (left; `ProjectMenu.tsx` project switcher on top, then slides) | canvas with floating `Toolbar.tsx` (undo/redo/add elements + ✨ Minta AI, bottom-center; the AI prompt `AgentBar.tsx` opens just above it). AI runs are owned by `agentRuns.ts` (module store, not component state): they survive project switches and closing the bar, history per project in localStorage, header pill / project menu / home cards show runs in other projects, toast with "Buka" when one finishes elsewhere. A page reload kills the server process (it dies with the connection), so stored runs become "interrupted") | inspector (right) with pinned `ExportBar.tsx`. Toasts are top-center (bottom-right would cover the export buttons).
  Inline text edit (`Canvas.tsx`): double-click a text element, or Enter/F2 on a selected one, makes the rendered node itself `contenteditable` (so it is WYSIWYG at any zoom/rotation). Commit = click away or Cmd/Ctrl+Enter (one undo step), Esc cancels; the node swallows keydown so editor shortcuts (Delete, arrows, P, undo) do not fire while typing, and the selected box gets `pointer-events:none` so clicks reach the text.
  AI scope (`AgentBar.tsx`): pills Seluruh project / Slide N / Elemen N follow the selection (click to pin). `scopeBlock()` prepends editor context to the prompt sent to the agent (restrict to this slide/element; variants = append with set_slide then reorder_slides); history shows `[Slide 3]`/`[Elemen 2]` tags. Chips per scope fill the prompt.
  Canvas zoom (`Canvas.tsx`, `ZoomControl.tsx`): state `zoom` (null = fit, else 0.1-4, 1 = 1 slide px per screen px), scroll container with hidden scrollbars, ctrl/cmd+wheel/pinch zooms at cursor, Space or middle-drag pans, mod +/-/0/1 shortcuts, resets to fit on slide change. All overlay math uses `scale`; keep it that way.
  Animation (present mode only): element `anim` {type fade|up|down|left|right|zoom|pop, delay, duration}, element `step` (0 = visible at once, N = Nth click/arrow), slide `transition` slide|fade|zoom. `renderSlideBody(..., {animate:true})` marks elements (`.cm-a`, `data-step`); `ANIM_CSS`/`stepCss` in `render.ts` drive them from wrapper attributes `data-active`/`data-cur` set by `SlideView` (changing those never rewrites the HTML, so animations do not restart). Keyframes use the individual `translate`/`scale` properties so they compose with the element's `rotate`. Editor canvas, PNG, PDF and lint never animate (final state). Inspector section "Animasi" per element, "transisi" per slide.
  Animated exports: `html` = one self-contained file (`present.ts`: images inlined as data URIs, tiny vanilla player with keys/click/swipe/steps/#n, F = fullscreen; web fonts from `tokens.css` @import still need network). `mp4`/`gif` = `renderVideo` in `headless.ts`: Playwright pauses every Web Animation and sets `currentTime` per frame (deterministic), steps auto-reveal every `stepGap` ms, each slide holds `hold` ms after its last animation, default swipe transition becomes a fade, frames pipe to system `ffmpeg` (libx264 yuv420p; gif = 720 px wide, 15 fps). Frames after the last animation are reused, so long holds are cheap.
  Presentation mode (`Present.tsx`, header "Presentasi" or Shift+P): browser fullscreen, one slide scaled to fill the screen, controls + cursor hide after 2.5 s idle. Reveals `step` elements before the next slide, plays `anim`/`transition`. Keys: arrows/Space/Enter, Home/End, B blackout, N speaker notes (`slide.notes`, edited in the inspector slide section) + next-slide thumb, L laser, T reset timer, F fullscreen. Leaving fullscreen (Esc is eaten by the browser) closes the mode via `fullscreenchange`; closing opens the last viewed slide in the editor.
  Repurpose (article/transcript -> carousel): MCP tool `fetch_source(url)` (`src/core/source.ts`) returns the page as plain text wrapped as UNTRUSTED content. The agent can be steered by what it reads, so the fetcher is strict: http(s) on 80/443 only, no credentials, no localhost/private/link-local/metadata addresses (checked on the address actually connected to via a custom `lookup`, and again on every redirect), 2 MB / 15 s / 5 redirects / 20k chars caps, HTML or text/plain only. Keep it that way; do not hand the agent `WebFetch`. `AiCreate.tsx`: URLs in the prompt add a "call fetch_source" instruction; pasted text > 400 chars (or multi-line) becomes a "Teks sumber" chip (max 30k chars) sent inside `<sumber>` tags, also marked as data. The system prompt in `agent.ts` tells the agent to paraphrase, one idea per slide, and credit the source on the last slide.
  Brand kits (`src/core/brands.ts`, `brands/<id>/brand.json` + logo file, next to `projects/`; override with `CAROUSEL_BRANDS`): palette, fonts, css, brief, logo. Applying COPIES (snapshot, not a live link, so renderer/exports are untouched and old exports never change): palette/fonts MERGE (brand wins on same name, project-only tokens stay so `{tokens}` used by slides never go missing), css and brief go in marked blocks (`/* brand:ID */...`, `[brand:ID]...[/brand]`) that a re-apply replaces, logo is copied to `assets/brand-logo.<ext>`, `brand` in the spec records the source. Slides are never touched. Delete = `brands/.trash`. API `/api/brands`, `POST /api/projects/:id/brand`; MCP `list_brands|get_brand|apply_brand|save_brand`. UI: `Brands.tsx` (`?brands=1`, sidebar "Brand kit"; same page layout as Planner: hero, brand cards on the left, info cards + full-color tips on the right; edit palette/fonts/css/brief/logo), `BrandRow` in Inspector > Tokens (apply / "Sinkron" / save project as brand), brand select in `NewProjectDialog` and `AiCreate` (applied before the agent starts, which is told to `get_brand` and use the tokens).
  Uploaded fonts (`src/core/fonts.ts`, pure helpers in `fontUtil.ts` shared with the web): files live in `projects/<id>/fonts/` (woff2/woff/ttf/otf, max 5 MB, magic bytes checked, a different file with an existing name is refused because slides already use that family); the ones a project USES are listed in the spec as `tokens.fontFiles`, so every renderer only needs the spec: `fontFaceCss(files, url)` emits `@font-face` (family = file name without extension, weight 100-900, `font-display:block`) after `tokens.css`. `RenderOpts.fontUrl` is the url mapper (headless serves `carousel.local/fonts/**` via `serveFonts`, HTML export inlines data URIs in `present.ts`, `SlideView` derives `/api/projects/:id/fonts` from `assetBase` so project, template and trash thumbnails all work; Playwright PNG/PDF/lint/video wait for `document.fonts.ready`). Upload = `POST /api/projects/:id/fonts/:name` (file only); the editor then attaches it with `attachFont` inside `ed.mutate` (adds the file to `fontFiles` and a `{Token}` to `tokens.fonts`, token key = family with non-word chars as `_`); MCP `add_font` does both. UI: `FontRow.tsx` in Inspector > Tokens ("Lepas" only detaches, files are never deleted; unattached files show "Pasang"). Duplicating a project copies `fonts/`; brands keep font files in `brands/<id>/fonts/` (`Brand.fontFiles`, filled by "save project as brand", copied+attached on apply); templates keep them in `templates/<id>/fonts/` and copy them on insert (existing project file of the same name wins). Known limit: @font-face is global in the browser, so two projects with different files under the same family name would clash on a page that shows both (Home thumbnails).
  Slide templates (`src/core/templates.ts`, pure helpers in `templateUtil.ts` shared with the web, `templates/<id>/template.json` + `assets/`, next to `projects/`; override `CAROUSEL_TEMPLATES`): a template = ONE slide + the format and tokens it was designed with. Save = `POST /api/templates` (slide JSON from the editor; images referenced as `assets/<file>` anywhere in the slide JSON are copied from the project; never overwrites, id = slug of the name). Insert = `POST /api/projects/:id/templates/:tid` copies the images into the project (same bytes = reused, different bytes with the same name = `-2` suffix and the slide is rewritten) and RETURNS `{slide, palette, fonts, css, mismatch}`; it does not touch the spec. The editor inserts it with `insertInstance` inside `ed.mutate` (one undo step, after `ed.flush()`), MCP `apply_template` does the same and saves. Tokens: only keys the project lacks are added (project wins), css goes in a `/* template:ID */` block. A format mismatch warns (positions are absolute px) but is allowed. UI: `TemplateDialogs.tsx` (gallery from the slide panel "Dari template", thumbnails via `/api/templates/:id/spec` = one-slide carousel + `SlideView`, filter format/tag/search; "Simpan sebagai template" dialog). Delete = `templates/.trash` (list/restore/purge on the trash page). MCP `list_templates|get_template|apply_template|save_template`; a template is a starting point, the agent must replace placeholder text and adapt the composition.
  Preview (`Preview.tsx`, header button or `P`): fullscreen swipe viewer on a Radix Dialog primitive (focus trap + Esc, and the global key handlers already ignore events inside dialogs). One clip box, all slides in a sliding track; drag/flick/wheel/arrows/dots. Closing opens the last viewed slide in the editor.
  Vite config graph (`vite.config.ts` -> `src/server/api.ts` -> `src/core/*`): relative imports there must carry the `.ts` extension and use `import.meta.dirname` (not `__dirname`), so the config also loads with `configLoader: 'native'` (future Vite default). `allowImportingTsExtensions` is on in tsconfig. Web code under `src/web` is bundled by Vite and can stay extensionless.
  Rulers + guides (`Rulers.tsx`, `GuidesLayer.tsx`, `Canvas.tsx`): rulers are drawn from `scale` and `origin` (slide (0,0) in viewport px, re-synced on scroll/zoom/resize). Guides live in the spec as `guides: {x:[], y:[]}` at project level (shared by all slides, editor-only, never rendered in exports); drag from a ruler to create, drag back onto the ruler or double-click to delete; the drag is local state and commits once (one undo step). Toggle rulers with Shift+R; both toggles are in the zoom menu.
  Snapping (`snap.ts`, `Canvas.tsx` startDrag): while dragging, the element's rotation-aware bounding box (left/center/right, top/middle/bottom) snaps to guides, slide edges and slide center within 6 SCREEN px (so it feels the same at any zoom). Resize snaps the right edge (and bottom for non-text) of unrotated elements only. Cmd/Ctrl while dragging disables it; toggle in the zoom menu (persisted). Snap lines are visual only (`SnapLayer`).
  Global key handler in `App.tsx` must ignore widgets that own arrows/Delete (slider, toggle group, select, menus), else they also nudge/delete the selected element.
  Reorder = drag and drop (`@dnd-kit`, `Sortable.tsx`): slides in `SlidePanel.tsx`, layers in `LayersList.tsx` (frontmost on top). Inspector = shadcn Accordion; field components must stay module-level (defining them inside a component remounts inputs and drops focus).
  Slide root sets default `color`/`font` in `render.ts` so slide content never inherits the editor theme and editor == export.
  Legacy editor CSS lives in `@layer components` in `styles.css`; never name a legacy class like a Tailwind utility (`.grid` once broke every dialog).
  App shell (`AppShell.tsx`): the non-editor pages (Home, Planner `?plan=1`, Brands `?brands=1`, Trash `?trash=1`) share a left sidebar (Project / Rencana konten / Brand kit / Sampah, collapsible, `carousel-sidebar` in localStorage); the editor has none. `App.tsx` `goPage(page)` is the only way to switch (it resets the other page flags); pages render `PageHeader title` inside the shell, `main` is forced `block` because legacy CSS makes `main` a flex container. ## Making a carousel (agent workflow)
1. `list_projects` / `create_project`. Then `get_carousel` (read `brief`) and `get_references` (look at the images).
2. If the user names a brand (or the project has `brand`), `get_brand` / `apply_brand` first and design with its `{tokens}` and logo. `set_meta`: format, brief, tokens (palette, fonts) ONLY for a new empty project. On an existing project never touch format/title/brief/tokens unless the user asked (the MCP refuses a format change when slides exist unless `allowFormatChange`). Tokens = shared look; layouts are NOT shared.
3. Images: `add_asset` (local file path) then element `src: "assets/<file>"`. Raw `<img>` inside `html` elements does not resolve `assets/`.
4. `set_slide` per slide, with a short `name` ("Hook", "Tip 2", "CTA"); without one the editor falls back to the biggest text. Every slide gets its own composition: vary scale, position, rotation, crop, bleed. No repeated layout, no template.
5. `render_slide` and look. Fix: cut-off text, weak contrast, empty areas, slides that resemble each other.
6. `lint` for overflow/off-canvas, then revise single slides with `set_element`/`set_slide`.
7. `export` (png per slide, pdf, html presentation, mp4/gif with animation) writes to `projects/<id>/out`. Export bar in the inspector has PNG / ZIP / PDF / HTML / MP4 / GIF buttons.

Elements: text, image, shape, html (raw HTML/SVG escape hatch). Style values accept `{token}` refs; numbers become px (except opacity, fontWeight, lineHeight, zIndex).
Editor and agent write the same file; last writer wins.
